# LexiClear

Upload a contract, policy or notice. LexiClear explains it in plain language,
flags the clauses that deserve attention, lists what it obliges you to do, and
answers questions about it using only your document — with citations.

Every finding quotes your document verbatim, and any finding whose quote cannot
be located in the source is discarded before you see it.

**Information, not legal advice.** Documents are held in memory for 30 minutes
and are never written to disk.

Full documentation, architecture notes and the test suite are in the repository
README.
